# Screen Inventory

## Primary navigation (accordion sidebar)
- **Overview** (sits outside groups)
- **Prospecting**: Discovery · Organisations · People · Qualification
- **Outreach**: Outreach Studio · Approvals · Inbox
- **Revenue**: Pipeline · Intelligence · Analytics
- **Workspace**: Tasks · Data Centre · Settings

## Screens
| Screen | Key content |
|---|---|
| Overview | Hero KPIs, pipeline chart, Chanakya summary, insight cards, heatmap, donut, weekly bars, benchmark, approval queue, activity feed, org table |
| Discovery | Candidate orgs w/ signals, campaigns, sources toggles |
| Organisations | Org cards (score, stage, value) → Quick View |
| People | Contact table (role, org, email verification, last contacted) |
| Qualification | Score rings, band, coverage, rationale |
| Outreach Studio | Draft list, composer (To picker + attachments), context panel |
| Approvals | Mariyada queue + draft review w/ policy checks |
| Inbox | Thread list + conversation + reply composer |
| Pipeline | Kanban columns by stage |
| Intelligence | Insight cards, buying signals, Sutradhar chat |
| Analytics | Funnel, donut, weekly, UK/IN benchmark |
| Tasks | Overdue / Today / This week groups |
| Data Centre | Import dropzone, recent imports, data quality bars |
| Settings | Settings nav + Founder voice (Writing DNA) |

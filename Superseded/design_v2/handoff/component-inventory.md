# Component Inventory

- **Sidebar** — accordion groups + Overview, badges, theme toggle, powered-by
- **KPI card** — label, delta (icon+sign), big value, sparkline, sub
- **Panel/section** — raised surface, card-edge, header eyebrow + title + action
- **Insight card** — icon chip, tag, headline, micro-bars, CTA
- **Charts** — area/line, donut, grouped bars, benchmark bars, heatmap, score ring (all `--chart-*`)
- **Approval queue row** — colour rail, title/meta, approve/reject
- **Activity feed item** — avatar initials, actor + action, time
- **Data table** — clickable rows, score chip, stage pill
- **Quick View drawer** — identity, score breakdown, contacts, evidence, action grid
- **Sutradhar panel** — header, structured response card, specialist chips, composer
- **Outreach composer** — recipient picker, subject, body, attachments, actions
- **Recipient picker** — DB contact rows (role + verification)
- **Attachment chip** — ext badge, filename, remove
- **Toggles/segmented** — date range, market, sources
